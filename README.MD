Implementação API City

Objetivos:

Deve ser implementada uma API utilizando SpringBoot onde seja possível expor operações de criação, delete, busca por todas as cidades ou busca por cidade por nome.

Devem ser implementadas as operações expostas como API Rest que consomem e de devolvem JSON.

Conforme definimos no apllication.properties o banco de dados a ser utilizado será o H2 em memória.

Verificar implementações de camada de serviço e persistência.

Deve ser levado em consideração o OpenAPI disponibilizado na pasta resources/openApi/openApi.json.

Observar boas práticas de clean code e padrões.
